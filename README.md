## 🤖 AI Usage and Verification

AI tools are part of my engineering workflow, but every suggestion is reviewed, tested, and verified before it becomes part of a project.

My responsible workflow:

1. 🤖 Use AI for explanations, drafts, starter examples, review suggestions, and troubleshooting support.
2. 📖 Validate important information with official documentation, course material, or trusted sources.
3. 🧪 Test commands, scripts, and configuration locally.
4. 🔐 Review security-sensitive suggestions carefully, especially IAM, secrets, CI/CD, and Kubernetes configuration.
5. ✅ Keep ownership of final technical decisions.
6. 📝 Document when AI helped and how the result was verified.

> AI is useful, but it is not the final authority. I am responsible for the final work.

## 🚦 AI Guardrails for My Projects

For technical projects, I use this workflow:

```text
AI suggestion or draft
        ↓
Manual review
        ↓
Local test or validation
        ↓
Security check if relevant
        ↓
Documentation update
        ↓
Commit to GitHub
```

For CI/CD and platform projects, the workflow becomes:

```text
Developer or AI-assisted change
        ↓
Pull Request
        ↓
Automated tests
        ↓
Linting and validation
        ↓
Security scans
        ↓
Human review
        ↓
Merge
```

This helps me practice responsible AI-assisted engineering in a realistic way.
